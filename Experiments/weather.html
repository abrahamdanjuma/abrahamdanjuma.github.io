Environment Log

A manual tool for tracking workspace context. No outside tracking.

Why this is manual

I know it's easier to just use an API to get the weather, but I don't really like how much data basic apps take from us. I built this because I wanted a tool that feels "quiet" and stays completely on my machine.

It’s not perfect, but it’s a simple way for me to track my work sessions without any tracking or servers involved. It's just a personal project to see if I could make something useful and private at the same time.
